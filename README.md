# IT3040 Assignment 1 – Singlish to Sinhala Transliteration Testing

## Project Overview

This repository contains the automated testing project for **IT3040 – Information Technology Project Management (ITPM), Assignment 1 – Option 1**.

The project evaluates the accuracy of the **PixelSuite Chat Translator** when converting informal **Singlish** text into **Sinhala Unicode** output.

The testing is focused on identifying cases where the system fails to correctly transliterate chat-style Singlish into Sinhala.

## System Under Test

**Application:** PixelSuite Chat Translator  
**Website:** https://www.pixelssuite.com/chat-translator  
**Feature Tested:** Chat Sinhala transliteration

The system accepts Singlish input typed using English characters and produces Sinhala output. This project checks whether the produced Sinhala output matches the expected Sinhala output for selected negative test scenarios.

## Assignment Scope

This project tests only the **Chat Sinhala transliteration** function.

The following areas are **not** tested:

- Standard Sinhala transliteration
- Backend APIs
- Performance testing
- Scalability testing
- Security testing

## Project Objectives

The objectives of this project are to:

- Identify 50 negative test cases where the transliteration output is incorrect
- Cover the required Singlish input types given in the assignment
- Automate the execution of test cases using Playwright
- Capture the actual Sinhala output from the website
- Compare actual output with expected output
- Record the test status in the Excel file
- Provide evidence/rationale for the Singlish input types covered

## Running the Automation

Make sure the Excel file is **closed** before running the script. If the Excel file is open, Python may not be able to save the results.

Run the following command from the project folder:

```bash
python .\test_automation.py --excel ".\Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 12000 --retries 25 --retry-wait-ms 2000 --type-delay-ms 120 --slow-mo-ms 300 --save-every 1 --keep-open
```

## Automation Workflow

The automation script performs the following steps:

1. Opens the PixelSuite Chat Translator website
2. Reads each test case from the Excel file
3. Types the Singlish input into the input field
4. Clicks the transliteration button
5. Captures the Sinhala output generated by the website
6. Compares the actual output with the expected output
7. Writes the actual output into the Excel file
8. Updates the status as PASS or FAIL
9. Saves the Excel file during execution

## Result Interpretation

### PASS

A test case is marked as **PASS** when the actual output exactly matches the expected Sinhala output.

### FAIL

A test case is marked as **FAIL** when the actual output does not match the expected Sinhala output.

For this assignment, the selected test cases are negative scenarios. Therefore, FAIL results represent weaknesses or transliteration inaccuracies in the system.

### UI Error

A **UI Error** may occur if the website does not return an output, the output does not update, or there is a temporary issue with the website.

If a UI Error appears, the test should be rerun after confirming that the website is working manually.

## Singlish Input Types Covered

The test cases are designed to cover different Singlish input patterns, including:

- Question forms
- Command forms
- Greetings
- Requests
- Responses
- Repeated words
- Inputs with punctuation marks
- Romanization / spelling variants
- Isolated English word insertions in Singlish
- Multi-word English phrases in Singlish
- English digital terms in Singlish
- Platform/app names in Singlish
- English abbreviations/acronyms in Singlish
- English clipped forms in Singlish
- Place names embedded in Singlish
- Person names embedded in Singlish
- Inputs with numbers and numeric suffixes
- Inputs with currency
- Inputs with time formats
- Inputs with dates
- Inputs with unit of measurements
- Inputs with slang and casual phrasing
- Online identifiers in Singlish
- Inputs containing emojis

## Troubleshooting

### Excel Permission Denied Error

If this error appears:

```text
Permission denied: Assignment 1 - Test cases.xlsx
```

Close the Excel file completely and run the automation again.

### File Not Found Error

If the script cannot find the Excel file, use the full file path or make sure the terminal is opened in the correct project folder.

Example:

```bash
python .\test_automation.py --excel "D:\SLIIT\3year1sem\ITPM\Test assign\test_automation\IT3040-Assignment1-Singlish-Transliteration-Testing\Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 12000 --retries 25 --retry-wait-ms 2000 --type-delay-ms 120 --slow-mo-ms 300 --save-every 1 --keep-open
```

### Failed to Fetch Error

If the website shows **Failed to fetch**, test the website manually first. Automation should be run only when the website successfully returns Sinhala output.
